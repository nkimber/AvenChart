# Security policy

## Experimental status

AvenChart is an experimental project and is not approved for production clinical use. Do not deploy it with protected health information or production credentials.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through GitHub's **Report a vulnerability** flow on the repository Security tab. Do not open a public issue for an unpatched vulnerability and do not include real patient or production data in a report.

Include the affected revision, component, reproduction conditions, expected impact, and a minimal synthetic proof when possible. Receipt and remediation timelines depend on maintainer availability; no service-level commitment is currently offered.

## Supported versions

Only the current `main` branch is considered for security fixes during the experimental phase.
